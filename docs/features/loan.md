> 한도 계산, 정책상품 자격, 상품 추천, 대출 계획
> LOAN-01 ~ LOAN-06
>
> ※ 표기 규칙과 기능 간 의존 관계는 「서비스 기능 정의서 — 개요」를 따른다.
> 작성 기준일 : 2026년 7월

## 5. 대출 (LOAN)

| ID | 기능명 | 설명 | 우선순위 |
| --- | --- | --- | --- |
| LOAN-01 | 대출 한도 계산 | LTV·DSR·Stress DSR 규제를 각각 계산해 사용자별 최대 대출 가능액을 산출하고, 세 한도 중 최솟값을 최종 한도로 한다. Stress DSR은 가산금리를 적용한 보수적 한도를 병기한다.<br>DTI는 한도 판정에 사용하지 않고 참고 수치로만 표시하며(dti_limit — 참고용), DSR과의 개념 차이(DSR은 전체 대출 원리금, DTI는 주담대 원리금 + 기타 대출 이자)를 안내 문구로 제공한다.<br>관련: LOAN_REGULATION, LOAN_PLAN, USER | 핵심 |
| LOAN-02 | 정책상품 자격 검토 | 버팀목 등 기금 대출의 자격 요건 중 시스템이 보유한 정보로 판정 가능한 항목(소득 한도, 무주택 여부, 기존 대출 이용 여부)을 검사해 항목별 충족·미충족 사유를 표시한다.<br>세대 구성 요건, 보증금 일부 지급 요건 등 보유하지 않은 정보에 해당하는 항목은 판정하지 않고 가입 시 확인 사항으로 안내한다. 매물 안전도와 개인 자격을 분리해 표시하는 보증보험 판정과 동일한 원칙을 적용한다.<br>관련: LOAN_PRODUCT, USER | 핵심 |
| LOAN-03 | 대출 상품 추천 | 두 단계 관문을 거쳐 추천한다. 1단계로 보증보험 가입이 가능한 매물만 추천 대상으로 삼고(위험한 매물에는 대출을 추천하지 않는다), 2단계로 소득 조건·주택 보유 조건 등 사용자 자격을 검사한다. 이후 규제를 적용한 한도를 산정하고 금리 오름차순 또는 한도 내림차순으로 정렬해 제시하며, 정책상품 자격 충족 시 이를 우선 배치한다.<br>관련: LOAN_PRODUCT, RISK_ANALYSIS, USER | 핵심 |
| LOAN-04 | 상환 시뮬레이션 | 상환방식(원리금균등·원금균등·만기일시)별 월 상환액과 총 이자를 비교한다.<br>관련: LOAN_PRODUCT | 부가 |
| LOAN-05 | 대출 계획 저장 | 추천 결과로 산출된 대출 계획(상품, 추천 금액, 월 상환액, 계산된 LTV·DSR·Stress DSR)을 매물 단위로 저장하고 조회한다. 계산 결과를 보존해 재조회 시 재계산하지 않으며, 상담의 예산 산출 입력으로도 사용된다.<br>관련: LOAN_PLAN | 필수 |
| LOAN-06 | 금리 변동 이력 | 기준금리·시장금리의 변동 추이와 대출 상품별 적용 금리의 변동 이력을 제공한다. 기준금리는 한국은행 API, 상품 금리는 금융감독원 금융상품 비교공시 API에서 배치가 수집해 적재한다.<br>관련: INTEREST_RATE_HISTORY | 부가 |
