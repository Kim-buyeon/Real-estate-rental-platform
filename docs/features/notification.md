## 7. 알림 (NOTI)

| ID | 기능명 | 설명 | 우선순위 |
| --- | --- | --- | --- |
| NOTI-01 | 알림 구독 관리 | 알림 유형별 수신 여부를 설정·해제한다. 신규 매물은 구독 조건(지역·계약유형·보증금 범위)을 함께 지정하고, 금리 변동과 관심 매물 모니터링은 수신 여부만 관리한다. 모니터링 수신을 켜면 등록된 관심 매물 전체가 대상이 된다.<br>관련: NOTIFICATION_SUBSCRIPTION, WISHLIST | 필수 |
| NOTI-02 | 알림 생성 | 다섯 유형의 트리거에 따라 알림을 생성한다. 신규 매물(구독 조건 매칭), 금리 변동(구독자 전체), 위험도 변경(관심 매물 모니터링 대상), 등기 변동(일 1회 점검에서 관심 매물의 갑구·을구 변경 감지), 상담 일정(예약된 전화 상담 시각 도래 전)이다. 생성은 트랜잭션 커밋 후 이벤트로 처리하고 중복을 차단한다.<br>관련: NOTIFICATION + 하위 4종, NOTIFICATION_SUBSCRIPTION, WISHLIST, CONSULTATION | 핵심 |
| NOTI-03 | 실시간 수신 | 접속 중 사용자에게 SSE로 알림 도착을 전달한다. 클라이언트는 수신 시 알림 목록을 재조회한다. | 핵심 |
| NOTI-04 | 웹 푸시 | 미접속 사용자에게 FCM으로 푸시를 발송한다. 권한 거부 시에도 앱 내 목록으로 동일 내용을 확인할 수 있다.<br>관련: NOTIFICATION | 부가 |
| NOTI-05 | 알림 목록 · 읽음 | 알림 이력을 조회하고 읽음 상태를 관리한다. 목록 조회가 알림의 완전한 확인 수단이다.<br>관련: NOTIFICATION | 필수 |
