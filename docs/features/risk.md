## 4. 위험도 분석 (RISK)

본 서비스의 핵심 영역이다. 등급 판정은 보증보험 가입 가능 여부를 1차 기준으로, 전세가율을 보조 기준으로 삼는 규칙 기반 3단계 판정이며, 산식과 임계값의 상세는 비즈니스 로직 정의서를 따른다.

| ID | 기능명 | 설명 | 우선순위 |
| --- | --- | --- | --- |
| RISK-01 | 위험 등급 판정 | 보증보험 가입 가능 여부(RISK-05)와 깡통전세 해당 여부(RISK-02)를 1차 기준으로, 전세가율을 보조 기준으로 삼아 3단계 등급을 판정한다. 깡통전세이거나 3사 모두 가입 불가면 DANGER, 가입 가능하되 전세가율 80% 이상이면 CAUTION, 그 외는 SAFE로 한다. 점수제가 아닌 규칙 기반 판정이며, 결과와 근거를 이력으로 저장한다.<br>관련: RISK_ANALYSIS, PROPERTY | 핵심 |
| RISK-02 | 깡통전세 판정 | 선순위채권(근저당 채권최고액 + 선순위 임차보증금)과 전세보증금의 합이 주택시세에 안전기준비율을 적용한 금액을 초과하는지 판정한다. 선순위채권 합계는 순위번호가 임차인보다 앞서고 현재 유효한 항목만 합산한다. 판정 결과는 등급 산출의 1차 입력이며, 해당 시 DANGER로 직결된다.<br>관련: RISK_ANALYSIS, MORTGAGE_HISTORY, PROPERTY | 핵심 |
| RISK-03 | 권리 침해 검출 | 등기 기재사항에서 압류·가압류·경매개시결정·신탁 등 권리 침해 등기의 존재를 검출한다. 검출 결과는 보증보험 판정의 집 단위 조건에 직접 반영되어 가입 불가 사유가 된다. 가등기, 임차권등기명령 등 보증 조건에 직결되지 않는 항목도 함께 검출해 사용자 눈높이의 설명과 함께 경고로 표시한다.<br>관련: OWNERSHIP_HISTORY, MORTGAGE_HISTORY | 핵심 |
| RISK-04 | 명의·문서 정합 확인 | 등기상 소유자와 임대인의 명의 일치, 대장 주소와 등기 주소의 일치, 위반건축물 여부, 등기 표제부 면적과 건축물대장 면적의 일치, 건물 용도의 주거용 여부를 대조한다. 명의 일치·주소 일치·위반건축물은 보증보험 집 단위 조건에 해당하므로 판정 결과가 RISK-05로 전달된다.<br>계약서와의 대조(계약 면적 일치, 주거용 오피스텔의 주거용 표기)는 시스템이 계약서를 보유하지 않으므로 판정하지 않고, 사용자가 직접 확인할 사항으로 안내한다.<br>관련: BUILDING_REGISTRY, BUILDING_LEDGER, PROPERTY | 핵심 |
| RISK-05 | 보증보험 가입 판정 | HUG·HF·SGI 각 기관에 대해 조건을 모두 만족하는지 검사하고, 하나라도 위배되면 해당 기관은 가입 불가로 판정한다. 집 단위 조건은 시스템이 판정한다. 전세가율 ≤ 기관별 담보인정비율, 보증금 한도, 대항력 요건은 본 기능이 직접 검사하고, 위반건축물 여부·명의 일치·대장 주소와 등기 주소 일치는 RISK-04의 결과를, 압류·가압류·경매개시결정·신탁의 존재 여부는 RISK-03의 결과를 입력으로 받는다. RISK-03·04가 검출하는 항목 중 가등기·임차권등기명령, 면적 대조, 계약서 대조 안내는 보증 조건에 해당하지 않으므로 판정에 반영하지 않는다. 개인 자격 조건(연소득 기준, 신청기한, 신규·갱신 구분, 주거용 표기)은 판정하지 않고 가입 시 확인 사항으로 안내한다. HF의 대출 연계 고유 조건을 별도 표기한다.<br>기관별 가입 가능 여부와 예상 보증료, 보증한도(주택가격 × 담보인정비율 − 선순위채권), 가입 가능한 보증 상품명을 근거 수치와 함께 제시한다. 3사 판정 결과는 등급 산출의 1차 입력이다.<br>관련: GUARANTEE_CRITERIA, HUG/HF/SGI_CRITERIA, GUARANTEE_PREMIUM_RATE, INSURANCE_PRODUCT | 핵심 |
| RISK-06 | 보증 신청기한 계산 | 개인 자격 조건 중 신청기한을 확인할 수 있도록, 사용자가 계약 시작일과 계약 기간을 입력하면 신청 가능 기한(계약기간 2분의 1 경과 전)을 즉석에서 계산해 마감일과 잔여 일수를 표시한다. 입력값은 저장하지 않는 무상태 계산 기능이다. | 부가 |
| RISK-07 | 등기 이력 조회 | 갑구(소유권)·을구(근저당) 변동 이력을 순위번호·접수일과 함께 시간순으로 표시한다. 접수일이 우선변제 순서를 결정함을 안내한다. 등기 데이터는 Mock 어댑터로 적재한다.<br>관련: BUILDING_REGISTRY, OWNERSHIP_HISTORY, MORTGAGE_HISTORY | 핵심 |
| RISK-08 | 위험도 재분석 | 재분석 계기는 세 가지다. 일 1회 배치의 시세 갱신에서 값이 변경된 매물, 일 1회 배치가 관심 매물의 등기를 재조회해 확인한 갑구·을구 변동, 사용자의 직접 요청이다. 시세는 전세가율·깡통전세·보증한도 산출에 모두 쓰이므로 등기가 그대로여도 등급이 바뀔 수 있다.<br>이전 등급을 보존하고 새 등급과 비교하여, 등급이 변경된 경우에만 알림 이벤트를 발행한다. 알림 발송 범위는 관심 매물 등록자로 한정한다. 동시 실행은 분산 락으로 차단한다.<br>관련: RISK_ANALYSIS, PROPERTY, WISHLIST, BUILDING_REGISTRY | 핵심 |
