# 전월세 부동산 금융 플랫폼 — 서비스 기능 정의서 — 회원

> 가입, 로그인, 자격 정보, 검색 이력, 탈퇴
> USER-01 ~ USER-05
>
> ※ 표기 규칙과 기능 간 의존 관계는 「서비스 기능 정의서 — 개요」를 따른다.
> 작성 기준일 : 2026년 7월

## 1. 회원 (USER)

| ID | 기능명 | 설명 | 우선순위 |
| --- | --- | --- | --- |
| USER-01 | 회원 가입 | 이메일 가입 및 카카오·네이버 소셜 가입을 지원한다. 소셜 가입 시 provider_id로 계정을 연결한다. 가입 시 권한은 일반 사용자로 부여한다.<br>관련: USER, USER_AUTH | 필수 |
| USER-02 | 로그인 · 토큰 갱신 | JWT 액세스 토큰과 리프레시 토큰을 발급한다. 리프레시 토큰은 Redis에 보관하고 재발급 시 회전한다.<br>관련: USER_AUTH | 필수 |
| USER-03 | 자격 정보 관리 | 연소득, 신용점수, 기존 대출, 주택 보유 여부, 계약에 투입 가능한 자기자금을 등록·수정한다. 대출 한도 계산과 계약 가능 범위 산출의 입력이며, 미입력 시 해당 기능이 제한됨을 안내한다.<br>관련: USER | 필수 |
| USER-04 | 검색 이력 | 매물 검색 조건을 자동 저장하고 최근 이력을 조회한다. 저장된 조건으로 재검색할 수 있으며, 상담 시 최근 관심 지역을 파악하는 컨텍스트로도 사용된다.<br>관련: SEARCH_HISTORY | 부가 |
| USER-05 | 회원 탈퇴 | 탈퇴 시 개인 식별 정보와 자격 정보를 파기하고, 관심 매물·검색 이력·알림 구독 설정을 함께 삭제한다. 상담 이력은 요약을 비식별 처리해 통계 목적으로만 보존한다.<br>관련: USER, USER_AUTH, WISHLIST, SEARCH_HISTORY, NOTIFICATION_SUBSCRIPTION, CONSULTATION | 필수 |
