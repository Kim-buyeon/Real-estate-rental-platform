> 작성 기준일 : 2026년 7월

## 3. 매물 (PROP)

| ID | 기능명 | 설명 | 우선순위 |
| --- | --- | --- | --- |
| PROP-01 | 매물 목록 검색 | 자치구·계약유형(전세/월세/반전세)·보증금 범위·매물유형·위험등급의 동적 조합으로 검색한다. 커서 방식으로 페이지를 넘긴다.<br>관련: PROPERTY, PROPERTY_CODE, RISK_ANALYSIS | 필수 |
| PROP-02 | 지도 드릴다운 탐색 | 지도를 3단계로 탐색한다. (1) 서울 전체 화면에서 자치구별 매물 수를 표시하고, (2) 자치구 선택 시 해당 구로 이동·확대하여 개별 매물 마커를 표시하며, (3) 마커 선택 시 상세 정보를 제공한다. 지도 이동·확대 시 표시 영역 내 매물을 재조회하고, 반경 조건은 바운딩 박스 1차 필터 후 거리 계산으로 확정한다.<br>단계 이동 시 적용 중인 필터를 유지하며, 상위 단계로 되돌아갈 수 있다.<br>관련: PROPERTY, RISK_ANALYSIS | 필수 |
| PROP-03 | 매물 상세 조회 | 기본 정보, 시세와 산출 근거(price_type·price_date), 최신 위험도 요약을 함께 제공한다.<br>관련: PROPERTY, RISK_ANALYSIS | 필수 |
| PROP-04 | 건축물대장 정보 | 위반건축물 여부, 용도, 면적을 표시한다. 국토부 API 수집 데이터를 사용한다.<br>관련: BUILDING_LEDGER | 핵심 |
| PROP-05 | 관심 매물 | 매물을 관심 목록에 등록·해제하고 목록을 조회한다. 관심 매물은 위험도 변경·등기 변동 알림의 발송 범위가 되며, 알림 수신 여부는 알림 구독 설정(NOTI-01)에서 일괄 관리한다.<br>관련: WISHLIST | 필수 |
| PROP-06 | 지역 시세 통계 | 자치구별 평균 보증금·거래량·기간 대비 변동률을 차트로 제공한다. 배치가 사전 집계한 결과를 조회한다.<br>관련: REGION_STATS | 부가 |
| PROP-07 | 전월세 전환 계산 | 전월세전환율을 적용해 보증금과 월세의 교환 비율을 계산한다. 보증금을 높여 월세 부담을 낮추거나 그 반대의 시나리오를 비교하고, 법정 전환율 상한과 관행 수준(보증금 1천만 원당 월세 약 10만 원)을 함께 표시한다. | 부가 |
| PROP-08 | 자치구별 매물 집계 | 적용된 필터 조건을 반영해 자치구별 매물 수를 집계한다. 필터를 변경하면 집계 결과가 즉시 갱신되어, 조건에 맞는 매물이 어느 지역에 분포하는지 파악할 수 있다. 필터 조합을 키로 캐싱하여 반복 조회 시 재집계하지 않는다.<br>관련: PROPERTY, RISK_ANALYSIS | 필수 |
