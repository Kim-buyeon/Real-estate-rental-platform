## 8. 관리자 (ADMIN)

판정에 사용되는 기준 데이터는 외부 정책 변경에 따라 값이 바뀐다. 이 값들을 코드가 아닌 테이블로 분리한 설계 의도를 살리려면 데이터베이스에 직접 접근하지 않고 값을 갱신할 수 있는 경로가 필요하다.
관리자 기능은 사용자 권한(USER.role)으로 접근을 제어한다. 권한은 일반 사용자와 관리자 두 가지이며, 별도의 관리자 계정 체계를 두지 않는다.

| ID | 기능명 | 설명 | 우선순위 |
| --- | --- | --- | --- |
| ADMIN-01 | 판정 기준 데이터 관리 | 보증보험 기관별 가입 기준(담보인정비율, 최대 보증금 한도), 보증료율, 대출 규제 수치(LTV·DSR·Stress DSR 한도)를 조회하고 수정한다. 정책 변경 시 배포나 데이터베이스 직접 접근 없이 값을 반영하기 위한 기능이다.<br>사용자 권한이 관리자인 경우에만 접근을 허용한다.<br>변경 이력을 남겨 특정 시점의 판정이 어떤 기준으로 산출되었는지 추적할 수 있게 한다. 변경 즉시 이후 판정에 반영되며, 기존 분석 이력은 소급 재계산하지 않는다.<br>관련: GUARANTEE_CRITERIA 및 서브타입, GUARANTEE_PREMIUM_RATE, LOAN_REGULATION | 부가 |
