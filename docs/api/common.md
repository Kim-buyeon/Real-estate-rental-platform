## 1. 공통 규약

모든 API는 REST 방식으로 제공하며 요청과 응답 본문은 JSON을 사용한다. 문자 인코딩은 UTF-8로 고정한다.

### 1.1 기본 규칙

| 항목 | 규약 |
| --- | --- |
| 기본 경로 | /api |
| 인증 | Authorization 헤더에 Bearer 토큰을 전달한다. 액세스 토큰은 JWT이며 만료 시 재발급 엔드포인트를 사용한다 |
| 자원 명명 | 복수형 명사와 소문자 하이픈 표기를 사용한다. 동사는 경로에 쓰지 않되, 조회가 아닌 처리 요청은 하위 경로에 동사형 명사를 둔다 |
| 인증 사용자 자원 | 토큰의 사용자에 종속된 자원은 /api/me 하위에 둔다. 자격 정보, 검색 이력, 관심 매물, 알림 구독 설정이 해당한다 |
| 필드 명명 | 요청·응답 본문의 필드는 소문자 카멜 표기를 사용한다 |
| 일시 표기 | ISO 8601 형식과 Asia/Seoul 시간대를 사용한다 |
| 금액 표기 | 원 단위 정수로 표기한다. 소수 자릿수가 필요한 비율은 문자열이 아닌 수치로 전달한다 |
| 열거값 | 대문자 스네이크 표기의 고정 문자열로 전달한다. 국내 제도 고유의 개념은 음차가 아니라 제도의 특성을 나타내는 영어 표현으로 명명한다 |

### 1.2 공통 응답 형식

모든 응답은 동일한 봉투 구조를 사용한다. 성공 시 data에 결과를, 실패 시 error에 사유를 담는다.
성공 응답

```json
{
  "success": true,
  "data": { }
}
```

목록 응답

```json
{
  "success": true,
  "data": {
    "items": [ ],
    "nextCursor": "eyJpZCI6MTAyNH0",
    "hasNext": true
  }
}
```

실패 응답

```json
{
  "success": false,
  "error": {
    "code": "PROFILE_INCOMPLETE",
    "message": "대출 한도 계산에 필요한 자격 정보가 없습니다.",
    "field": "annualIncome"
  }
}
```

### 1.3 상태 코드

| 코드 | 의미 | 사용 상황 |
| --- | --- | --- |
| 200 | 성공 | 조회 및 처리 완료 |
| 201 | 생성됨 | 회원 가입, 관심 매물 등록, 상담 시작 |
| 204 | 내용 없음 | 삭제 완료 |
| 400 | 잘못된 요청 | 필수 파라미터 누락, 형식 오류 |
| 401 | 인증 실패 | 토큰 없음 또는 만료 |
| 403 | 권한 없음 | 관리자 전용 자원에 일반 사용자가 접근 |
| 404 | 없음 | 존재하지 않는 매물·상담·알림 |
| 409 | 충돌 | 중복 가입, 이미 등록된 관심 매물 |
| 422 | 처리 불가 | 자격 정보 미입력 상태에서 한도 계산 요청 |
| 429 | 요청 과다 | 재분석 요청 간격 제한, 상담 호출 한도 초과 |
| 503 | 일시적 불가 | 외부 연동 장애로 분석 또는 상담 응답 불가 |

### 1.4 페이지네이션

- 목록 조회는 커서 방식을 사용한다. 요청에 cursor와 size를 전달하고, 응답의 nextCursor를 다음 요청에 그대로 넣는다.
- size의 기본값은 20, 최댓값은 100으로 한다.
- 전체 건수는 반환하지 않는다. 필요한 화면에서는 별도의 집계 엔드포인트를 사용한다.

### 1.5 인증 구분 표기

| 표기 | 의미 |
| --- | --- |
| 공개 | 인증 없이 호출 가능 |
| 선택 | 인증 없이도 호출되나, 인증 시 개인화된 결과를 반환 |
| 필수 | 유효한 액세스 토큰 필요 |
| 관리자 | 권한이 관리자인 사용자만 호출 가능 |

## 2. 오류 코드

| 코드 | 상태 | 설명 |
| --- | --- | --- |
| AUTH_TOKEN_EXPIRED | 401 | 액세스 토큰 만료. 재발급 필요 |
| AUTH_INVALID_CREDENTIAL | 401 | 인증 정보 불일치 |
| AUTH_FORBIDDEN | 403 | 권한 부족 |
| USER_DUPLICATED | 409 | 이미 가입된 이메일 또는 소셜 계정 |
| PROFILE_INCOMPLETE | 422 | 한도 계산에 필요한 자격 정보 미입력 |
| PROPERTY_NOT_FOUND | 404 | 존재하지 않는 매물 |
| RISK_NOT_ANALYZED | 404 | 아직 분석되지 않은 매물 |
| RISK_REANALYZE_TOO_SOON | 429 | 재분석 최소 간격 미경과 |
| WISHLIST_DUPLICATED | 409 | 이미 등록된 관심 매물 |
| LOAN_PROPERTY_NOT_ELIGIBLE | 422 | 보증보험 가입 불가 매물로 추천 대상 아님 |
| CONSULT_QUOTA_EXCEEDED | 429 | 상담 호출 한도 초과 |
| CONSULT_OUT_OF_SCOPE | 200 | 응답 범위 밖. 오류가 아닌 안내로 처리 |
| EXTERNAL_API_UNAVAILABLE | 503 | 외부 연동 장애 |
