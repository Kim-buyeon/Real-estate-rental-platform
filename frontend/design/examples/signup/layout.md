### 비활성 버튼 계측 — 이 컷의 핵심

| 항목 | 값 | 신뢰도 |
| --- | --- | --- |
| 배경 | `{colors.disabled-surface}` ≈ `#d8d8d8` | 추정 |
| 글자 | `{colors.text-disabled}` — 계측값은 `#ffffff`, 정의서 채택값은 `#999999` (K-01) | 추정 — `#f5f5f5` 일 수 있다. **참고 사이트의 대비가 ≈1.4:1 로 매우 낮아 채택하지 않았다** |
| 타이포 | `{typography.button}` — 활성과 동일 | 추정 |
| 높이 · 폭 · 반경 | **활성과 동일** (60 · 100% · `{rounded.sm}`) | 측정 |
| 테두리 | 없음 | 측정 |
| 투명도 | 별도 opacity 적용 흔적 없음. 배경색 자체를 바꾼 것으로 보임 | 추정 |

> 이 조합(흰 글자 / `#d8d8d8` 배경)은 **대비비 ≈ 1.4:1** 로 WCAG 비텍스트 대비 기준에 한참 못 미친다. 그대로 베끼지 말 것 — author가 우리 값으로 정해야 한다. Known Gaps 로 올린다.

## 여백 리듬

| 구간 | 값 |
| --- | --- |
| 카드 패딩 | 80 `{spacing.5xl}` |
| 제목 ↔ 구분선 | 48 |
| 구분선 ↔ 안내문 | 34 |
| 안내문 ↔ 첫 field | 62 |
| 라벨 ↔ 입력 | 12 `{spacing.sm}` |
| 같은 field 안 입력 ↔ 입력 | 12 `{spacing.sm}` |
| field ↔ field | 44 |
| 마지막 입력 ↔ 주 버튼 | 60 |

> `login` 은 「입력 ↔ 주 버튼 34」, `signup` 은 60 이다. **같은 역할인데 값이 다르다.** 둘 다 1회 관측이므로 author가 하나로 정해야 한다 (권장: 48).

### 제안(미관측)

`login` 의 제안과 동일하게 접는다 — `examples/login/layout.md` 「반응형 붕괴」 참조. 추가로:

- 모바일에서 같은 field 안의 입력 2개 간격 12는 **유지**한다. field 사이(24로 축소)와 시각적으로 구분되어야 한다
- 비활성 버튼도 높이 52로 같이 줄인다. 비활성이라도 터치 타겟 44는 확보
- 약관 동의 `checkbox` 는 참고 사이트 컷에 **없다.** 우리 회원가입에 필요하면 author가 정의한다 (Known Gaps G-07)
