# home layout (푸터 구역만) — source: dabangapp

> 컷: `reference-desktop-03-content-footer.jpg` (정본) · 교차 확인 `login/01` · `signup/01` · `favorites/01-03` · `listing/06`
> 단위는 CSS px. 배율 근거는 `analysis/tokens.md` 0장 (**배율 ×1.0 확정**).
> 토큰 이름은 `DESIGN.md` 프론트매터 기준이다 (계측 단계 이름은 `analysis/tokens.md`).

## 범위

**푸터 구역 하나만 담는다.** `home` 은 우리가 만들지 않는 화면이고(`input.md` 3장), 푸터만 전 페이지 공통 요소라서 우리가 그대로 만든다. 히어로 · 카드 그리드 · 광고 블록 · 추천 매물 그리드는 레이아웃 대상이 아니다 — 토큰과 컴포넌트 계측에만 썼다.

> 참고: `home/01` · `home/02` 는 다른 컷보다 **약 1.35배 확대 캡처**되어 있어 레이아웃 기준으로 쓰지 않았다 (`analysis/tokens.md` 0.2). `home/03` 은 다른 컷과 같은 배율이라 푸터 계측의 정본으로 쓴다.

## 섹션 순서 (위 → 아래)

site-footer 는 **4구역**이다. 구역 2~4는 같은 어두운 면 위에 이어지고, 구역 1만 흰 면이다.

| # | 구역 | 배경 | 높이 | 화면 전폭 여부 |
| --- | --- | --- | --- | --- |
| 1 | **sitemap** | `{colors.surface}` | ≈ 210 | 배경 전폭, 내용은 컨테이너 |
| 2 | **link-bar** (링크줄 + 검색 + TOP) | `{colors.footer-surface}` | 88~100 | **배경 화면 전폭**, 내용은 컨테이너 |
| 3 | **business-info** | `{colors.footer-surface}` | ≈ 200 | 〃 |
| 4 | **copyright** | `{colors.footer-surface}` | ≈ 40 | 〃 |

**구분선은 딱 하나다** — 구역 2와 3 사이의 1px `{colors.footer-divider}` 가로선. 이 선은 **화면 전폭이 아니라 컨테이너 폭(1330)** 이다. 구역 3↔4 사이에는 선이 없다.
구역 1과 2의 경계는 배경색이 흰색 → 어두운 색으로 바뀌는 것 자체다. 별도 보더 없음.

## 그리드 / 컨테이너

- 고정 컨테이너 **1330**, 좌우 auto 중앙. **모든 구역이 같은 컨테이너를 쓴다** (측정: `home/03` 600→1930, `listing/06` 588→1915, `login/01` 600→1928, `favorites/01` 617→1944 — 뷰포트가 2518~2559로 41px 변해도 폭이 1327~1330 불변 → 고정 폭)
- 어두운 배경은 컨테이너를 넘어 **화면 전폭**으로 깔린다

## 구역 2 — link-bar

좌우 2블록. 좌측은 정책 링크, 우측은 검색 셀 + TOP 셀.

| 항목 | 값 | 신뢰도 |
| --- | --- | --- |
| 구역 높이 | 88~100 (컷 간 편차. `analysis/tokens.md` G-05) | 측정(±12) |
| 좌측 링크 수 | **4** | 측정 |
| 구분자 | `|` · 링크와 좌우 각 16 | 측정 |
| 링크 글자 | `{typography.link}` · `{colors.on-footer}` | 추정 |
| **강조 링크** | 4개 중 1개만 700 + `#ffffff` | 측정(구조) / 추정(색) |
| 링크 세로 정렬 | 구역 높이 중앙 (위아래 여백 대칭 측정) | 측정 |
| **검색 셀 폭** | **329** | 측정 |
| **TOP 셀 폭** | **73** | 측정 |
| 세로 구분선 | **2개** — 검색 셀 좌측, TOP 셀 좌측. 1px `{colors.footer-divider}` · 구역 2 높이 전체 | 측정 |
| 검색 입력 | 배경·보더 없음(푸터 면 그대로) · placeholder `{colors.on-footer}` `{typography.link}` · 우측 돋보기 아이콘 20 · 좌 패딩 16 | 측정 |
| TOP | 위 방향 삼각형(8) + 「TOP」 `{typography.caption}` **2줄 중앙 정렬** · 셀 전체가 버튼 | 측정 |
| 구역 하단 구분선 | 1px `{colors.footer-divider}` · **컨테이너 폭 1330** | 측정 |

> 검색 셀과 TOP 셀은 컨테이너 **우측 끝에 붙는다** (TOP 셀 우변 = 컨테이너 우변). 좌측 링크와의 사이는 빈 공간이다.

## 반응형 붕괴

**미관측 — 데스크톱 컷만 있음.** 6개 컷 모두 뷰포트 2518~2559px 의 초광폭 데스크톱이다. 모바일·태블릿 푸터 컷이 없다.

아래는 승인된 브레이크포인트(모바일 ~767 / 태블릿 768~1023 / 데스크톱 1024~, 컨테이너 max 1200)에서의 **제안(미관측)** 이다. 계측값이 아니다.

### 제안(미관측) — 데스크톱 1024~

- 컨테이너 1330 → 우리 정의 **`max-width: 1200`** · 좌우 패딩 24
- sitemap 6컬럼 유지 → 컬럼 폭 (1200-48) ÷ 6 = 192
- link-bar 검색 셀 329 · TOP 셀 73 그대로. 좌측 링크와의 빈 공간만 줄어든다

### 제안(미관측) — 태블릿 768~1023

- 컨테이너 100% · 좌우 패딩 24
- sitemap **6컬럼 → 3컬럼 2행**. 컬럼 폭 (768-48) ÷ 3 = 240. 행 사이 40
- link-bar 유지. 검색 셀 329 → 240 으로 축소, TOP 셀 73 유지
- business-info · copyright 그대로

### 제안(미관측) — 모바일 ~767

- 컨테이너 100% · 좌우 패딩 16
- **sitemap 은 접는다.** 6컬럼 → 아코디언 6개(각 높이 52, 구분선 1px `{colors.border}`) 또는 전체 생략. 링크 31px 줄높이 × 최대 5줄 × 6컬럼을 세로로 펼치면 푸터가 과하게 길어진다
- link-bar **2줄로 접는다**
  - 1줄: 정책 링크 4개 (넘치면 2줄 랩, 줄 피치 32)
  - 2줄: 검색 입력 100% (높이 48) — 세로 구분선 제거
  - **TOP 은 셀에서 빼내 화면 우하단 고정 원형 버튼(48)** 으로 전환
- business-info: 줄 피치 20 유지, 글자 13 유지. 소형 버튼 4개는 **2×2 랩** (갭 8)
- 소셜 버튼: 우측 정렬 → **좌측 정렬 · 버튼 줄 아래 24** 로 내린다 (같은 y 유지 불가)
- copyright 그대로
- 구역 2↔3 구분선은 컨테이너 폭 → 좌우 패딩 안쪽 폭

> 참고 사이트가 모바일에서 사이트맵을 아코디언으로 접는지 아예 감추는지는 **확인할 수 없다.** 위는 제안이다.
